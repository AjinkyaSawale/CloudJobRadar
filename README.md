# CloudJobRadar

CloudJobRadar is a Python-based job discovery and tracking tool designed for Cloud, DevOps, Platform Engineering, and Site Reliability Engineering roles.

## Problem

Relevant jobs are distributed across many company career portals. Checking every portal manually is time-consuming and makes it easy to miss newly published opportunities.

## Proposed Solution

CloudJobRadar will automatically collect jobs from selected company career portals, filter them by role and location, remove duplicates, and display matching opportunities in one dashboard.

## Initial Scope

- Cloud, DevOps, Platform Engineer, and SRE roles
- Ireland, India, and remote opportunities
- Greenhouse and Lever career portals
- Duplicate job prevention
- Job application status tracking
- Automated daily job scans

## Planned Technology

- Python
- Streamlit
- SQLite
- Pytest
- GitHub Actions

## Project Status

The project is currently in the planning and foundation stage.
